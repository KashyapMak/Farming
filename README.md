# ખેતી માર્ગદર્શિકા

## ખેડૂતો માટે ગુજરાતી ખેતી માહિતી

ખેતી સંબંધિત ઉપયોગી અને વ્યવહારુ માહિતી ખેડૂતો તેમજ ખેતી વિશે જાણવા ઇચ્છતા દરેક વ્યક્તિ સુધી પહોંચાડવાનો આ પ્રયાસ છે. આ રિપોઝિટરીમાં ઉપલબ્ધ માહિતી ગુજરાતી ભાષામાં આપવામાં આવે છે, જેથી સ્થાનિક ખેડૂતો તેને સરળતાથી સમજીને ઉપયોગ કરી શકે.
---
## કેસર કેરી

### કેસર આંબાની વૈજ્ઞાનિક અને નફાકારક ખેતી

કેસર આંબાના વાવેતરથી લઈને લણણી, સંગ્રહ, મૂલ્યવર્ધન અને બજાર વ્યવસ્થા સુધીની ખેતીલક્ષી માહિતી અહીં આપવામાં આવી છે. આ માર્ગદર્શિકા નવા બગીચા શરૂ કરતા ખેડૂતો, હાલના બગીચાના માલિકો અને નિકાસલક્ષી ઉત્પાદન કરવા ઇચ્છતા ખેડૂતો માટે ઉપયોગી છે.

- **સંપૂર્ણ વિગતો:** [કેસર આંબાની વૈજ્ઞાનિક અને નફાકારક ખેતી](Mango/keshar-mango.md)
	જમીન અને પાણીની તપાસ, કલમની પસંદગી, વાવેતર, ટપક સિંચાઈ, પોષણ, રોગ-જીવાત નિયંત્રણ, FPO, સંગ્રહ અને નિકાસ વિશે વિસ્તૃત માર્ગદર્શિકા.

- **ટૂંકી વિગતો (PDF):** [કેસર આંબાની ખેતી માર્ગદર્શિકા PDF](Mango/Keshar_Mango_Farming_Guide_Gujarat.pdf)
	ઑફલાઇન વાંચન અને સાચવી રાખવા માટેનું સંક્ષિપ્ત ગુજરાતી PDF સંસ્કરણ.
